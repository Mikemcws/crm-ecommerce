# 📦 CRM Store

Sistema de CRM desenvolvido para gestão de clientes e leads de e-commerce.
Projeto construído do zero com HTML, CSS e JavaScript puro.

## 🚀 Demo

👉 [Acesse o projeto aqui](https://seu-link-aqui.vercel.app)

**Login de acesso:**
- E-mail: `admin@crm.com`
- Senha: `123456`

## ✨ Funcionalidades

- 🔐 Autenticação com proteção de rotas
- 📊 Dashboard com KPIs em tempo real
- 👥 CRUD completo de clientes com busca e filtros
- 🎯 Funil de leads com Kanban e drag and drop
- ✅ Gestão de tarefas com prioridade e alertas de atraso
- 💾 Persistência de dados com localStorage

## 🛠️ Tecnologias

- HTML5
- CSS3 (Flexbox, Grid, animações)
- JavaScript (DOM, eventos, localStorage)
- Git e GitHub
